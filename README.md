Сначала пишется парсер main.py, где каждая строка выводит все параметры для белка egfr, что эквивалентно  https://www.ebi.ac.uk/chembl/api/data/activity.json?target_chembl_id=CHEMBL203&standard_type=IC50&limit=100&offset=0

После того, как был запущен парсер assay (экспериментов, в которых испытывались молекулярные структуры в качестве ингибиторов для белка egfr у организма Homo sapiens) 02b_fetch_assay_confidence.py
у нас будут все данные с экспериментами, которые были получены с помощью этого парсера
Итого: у нас 2 парсера - первый парсер (activities, main.py), собирает все данные молекул и IC50, второй парсер собирает все данные об эксперименте

После этого мы соединяем в файле 03_clean_activities.py - «фильтрация и расчёт pIC50», (зачем нужно считать pIC50, а не IC50), который превращает сырую выгрузку (26 600 записей обо всём, что попалось) в данные, пригодные для обучения модели. Лог показывает, что скрипт делает по порядку. pIC50 = 9 − log10(IC50 в нМ) - нужно для того, чтобы минимизировать сильный разброс значений IC50
